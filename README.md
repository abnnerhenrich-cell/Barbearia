# BRAVO — Agenda e painel 2.0

Leia **INICIAR-AQUI.md** para configurar, testar e publicar.

Esta versão usa Flask + PostgreSQL (Neon) e hospedagem Vercel. Mantém o visual BRAVO e a foto original. Reservas são gravadas no banco e bloqueiam intervalos por profissional. Painel administrativo em `/admin` permite confirmar, cancelar, concluir e bloquear pausas.

Não há senha padrão, pagamento online, envio automático de mensagens nem publicação no GitHub Pages. Catálogo, equipe e horários são configurados em `settings.json`.
